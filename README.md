Scientific Calculator – Java Swing UI

A fully functional Scientific Calculator built using Java Swing.
This calculator supports basic arithmetic operations as well as advanced scientific functions like trigonometry, logarithms, power, and square root.

 Features
✔ Basic Operations

Addition

Subtraction

Multiplication

Division

✔ Scientific Functions

sin(x)

cos(x)

tan(x)

log (Base 10)

ln (Natural Log)

sqrt (Square Root)

x^y (Power Function)

✔ UI Features

Clean button layout

Click-based input

Real-time display

Error handling

Responsive button action


🚀 How to Run This Project
1. Install Java

Make sure Java (JDK 8 or above) is installed.

Check with:

java -version

2. Compile the program

javac ScientificCalculatorUI.java

3. Run the program
java ScientificCalculatorUI

A full scientific calculator window will appear.
